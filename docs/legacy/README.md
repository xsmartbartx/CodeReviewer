# Legacy material

`awesome-coderabbit/` is the curated list of CodeRabbit resources this repository contained before it became CodeReviewer: the original README, contribution guide, code of conduct, architecture notes, decision records, and configuration schema. It is kept for reference and is not maintained.

That material was published under CC0 1.0 Universal (see `awesome-coderabbit/LICENSE.md`) and remains under that dedication. Its six example configurations now live in [`../../examples/coderabbit/`](../../examples/coderabbit/), where they serve as fixtures for CodeReviewer's `.coderabbit.yaml` compatibility.
